Subsequent code addresses invocation-scoped command deduplication (F01), transactional zone unassignment and undo normalization (F02), reachable advertising eligibility and privacy cancellation (F03/F06), reminder delivery/environment/failure handling (F04/F05), persistent restore/reset recovery and cancellation-safe compensation (F05/F06), stronger production-path assertions (F08), and resource-injected EN/RU CSV headers (F10). CSV localizes headers while preserving authored row values and excluding photo bytes.
