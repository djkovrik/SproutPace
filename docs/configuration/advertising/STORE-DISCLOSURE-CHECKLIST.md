# Store disclosure checklist

Complete this only when preparing an externally distributed build. It is a template, not evidence of legal approval or store submission.

- [ ] Final HTTPS privacy-policy URL is public and matches the in-app link.
- [ ] Approved EN/RU consent text accurately describes the app-owned Yandex-only choice.
- [ ] Store privacy/data-safety answers cover Yandex Mobile Ads and separately cover Crashlytics.
- [ ] No claim describes the region endpoint as an IAB TCF CMP.
- [ ] No mediation, Google demand, Analytics, attribution, ATT, location, or advertising-ID collection is declared unless a later approved scope actually adds it.
- [ ] Android production ad unit is an inline Yandex unit and the release guard passes.
- [ ] Android device verification records protected/non-protected/failing routes and withdrawal behavior.
- [ ] iOS advertising remains declared absent and disabled.
